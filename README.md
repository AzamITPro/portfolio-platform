# Personal Portfolio & Professional Profile Platform

A production-grade, full-stack personal portfolio and professional profile management platform engineered with modern web standards.

## 🚀 Tech Stack

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** FastAPI (Python), SQLAlchemy 2.0, Pydantic v2, Alembic
- **Database:** PostgreSQL
- **Security:** HttpOnly Secure Cookies, JWT, Argon2/Bcrypt, Rate Limiting
- **Architecture:** Decoupled Clean Layered Architecture
